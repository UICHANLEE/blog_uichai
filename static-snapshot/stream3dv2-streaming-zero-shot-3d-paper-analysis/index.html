Stream3Dv2 논문 분석: 2D Mask를 스트리밍 3D Instance로 묶는 법

RGB-D·camera pose·intrinsic을 받아 SAM2·SAM3 mask를 3D instance로 누적하는 과정과 ScanNet200 비교 결과, training-free와 11 FPS의 범위를 분석합니다.

로봇이 방을 이동하는 동안 처음 보는 물체까지 3D 공간에서 계속 분리해 낼 수 있을까? Stream3Dv2는 순서대로 들어오는 RGB-D 프레임을 최근 20개씩 묶어 분석한 뒤, 새로 얻은 3D 인스턴스를 기존 지도에 이어 붙인다. SAM2의 넓은 물체 커버리지와 SAM3의 의미 정보를 결합하고, 곡면을 따라가는 manifold 거리로 마스크 경계를 보완한다.

논문은 ScanNet200의 streaming zero-shot 조건에서 class-agnostic AP 27.1, semantic AP 20.6과 비교표상 11 FPS를 보고한다. 다만 이것을 “모든 3D 이해 모델 중 SOTA이며 전체 로봇 시스템이 11 FPS로 돈다”라고 읽으면 안 된다. 더 높은 class-agnostic AP를 기록한 offline·supervised 방법이 있고, 11 FPS가 어느 전처리와 모델 추론까지 포함하는지도 논문은 명확히 나누지 않았다. 이 글에서는 입력과 처리 과정, 출력, 비교 조건을 분리해 Stream3Dv2가 실제로 해결한 문제를 살펴본다.

1. 논문이 해결하려는 문제

논문의 정식 제목은 Stream3Dv2: Geometric-Semantic Fusion Enhanced Streaming Zero-Shot 3D Scene Understanding이다. Jie Xu와 Na Zhao가 작성했으며, 두 저자 모두 Singapore University of Technology and Design의 ISTD Pillar에 소속돼 있다. arXiv v1 공개일은 2026년 8월 21일이다.

기존 zero-shot 3D segmentation은 보통 한 장면의 RGB-D 전체와 완성된 point cloud를 확보한 뒤, 모든 frame의 2D mask를 한꺼번에 3D로 올려 합친다. 정확도에는 유리하지만, 로봇이 지금 막 본 프레임을 처리하려면 미래 frame까지 기다려야 한다. 새 frame이 올 때마다 전체 sequence를 다시 계산하면 관측 길이에 따라 비용도 계속 커진다.

Stream3Dv2가 겨냥한 Streaming Zero-Shot 3D Instance Segmentation은 조건이 더 빡빡하다. 시점 t에서 사용할 수 있는 새 관측은 현재 RGB-D뿐이고, 이전에 쌓은 point cloud와 instance mask를 상태로 보존하면서 결과를 증분 갱신해야 한다. 동시에 특정 3D 데이터셋의 label로 새 network를 학습하지 않고, 2D foundation model의 지식을 3D로 이전해야 한다.

‘training-free’와 ‘zero-shot’의 정확한 뜻

여기서 training-free는 아무 모델도 학습하지 않았다는 뜻이 아니다. Stream3Dv2의 3D 병합·분할·역사 갱신 모듈을 ScanNet200 같은 target dataset에서 추가 학습하지 않는다는 뜻이다. 2D mask와 언어 의미는 대규모 데이터로 이미 사전학습된 SAM2, SAM3, CLIP에서 가져온다.

  • 새로운 3D backbone을 dataset label로 fine-tuning하지 않는다.
  • SAM2·SAM3·CLIP의 pretrained weight와 계산 비용은 여전히 필요하다.
  • window size, 거리·IoU threshold, sampling rate 같은 parameter는 사람이 정한다.
  • open-vocabulary도 완전한 무제한 어휘가 아니라, 평가 때 제공한 class word와 prompt 설계의 영향을 받는다.

2. Input — 무엇이 반드시 준비돼야 하나

RGB-D와 시간순 frame

각 시점에는 RGB image와 같은 시점의 depth map이 필요하다. RGB는 SAM2·SAM3가 2D mask를 만들고 CLIP이 image-text 유사도를 계산하는 데 쓰인다. depth는 mask에 포함된 pixel을 카메라 좌표의 3D point로 역투영하는 데 쓰인다. Monocular RGB 영상만 바로 넣어 동일한 pipeline을 돌리는 모델은 아니다.

Camera intrinsics와 pose/extrinsics

Depth pixel을 3D ray로 바꾸려면 focal length와 principal point를 담은 camera intrinsics가 필요하다. 서로 다른 frame에서 얻은 point를 하나의 좌표계에 겹치려면 시점별 camera pose인 camera-to-world 변환도 필요하다. 논문은 depth와 camera pose로 point cloud가 재구성돼 있다고 두며, 공개된 v1 저장소의 ScanNet data layout에도 intrinsic_depth.txt와 frame별 pose가 별도 입력으로 등장한다.

중요한 점은 Stream3Dv2가 depth estimation, calibration, visual odometry나 SLAM 자체를 해결하지 않는다는 것이다. pose가 흔들리면 같은 의자에서 나온 point가 전역 좌표상 어긋나고, 3D IoU와 AABB overlap이 함께 무너진다. 실무에서는 RGB-D sensor calibration과 안정적인 pose tracking이 모델 앞단의 필수 조건이다.

현재 frame 외에 유지하는 상태

처음에는 RGB-D와 pose만 들어오지만, 운영 중에는 최근 k개 frame의 local point cloud와 mask, 첫 frame부터 쌓인 point cloud, 이미 생성한 historical instance mask가 내부 상태가 된다. 논문의 기본 window는 k=20이다. 매 시점 전체 영상을 다시 보는 대신 최근 20개 view에서 local consistency를 만들고, 그 결과만 역사 지도에 결합한다.

Text prompt와 class word

SAM3의 semantic-prompted segmentation에는 desk, chair 같은 common scene class word가 들어간다. 논문은 기존 CLIP 기반 연구와 같은 class word를 사용했다고 설명한다. Geometry branch는 prompt 없이 물체 후보를 넓게 찾지만, semantic branch가 어떤 세부 물체를 분리할지는 제공한 단어 목록의 영향을 받는다.

3. Output — 모델이 내놓는 결과

  • Class-agnostic 3D instance mask: 이름을 붙이기 전, point index 집합으로 분리한 개별 물체.
  • Semantic 3D instance mask: 각 instance에 open-vocabulary class label을 연결한 결과.
  • 3D object detection: instance point의 x·y·z 최소·최대값으로 만든 axis-aligned bounding box.
  • Historical scene state: 지금까지 관측된 영역의 mask를 새 frame마다 갱신한 object-centric 3D map.

출력은 point cloud 위의 instance segmentation이지, watertight mesh나 물체의 6D pose, 관절 상태, 이동 속도를 직접 추정하는 결과가 아니다. 논문이 historical mask를 static과 dynamic으로 나누지만, 여기서 dynamic은 현재 local mask와 point가 겹쳐 갱신 대상이 된 historical instance라는 algorithm 내부 분류다. 실제 움직이는 물체를 추적하거나 motion vector를 추정했다는 뜻으로 읽으면 안 된다.

4. Process — RGB-D 한 장이 3D instance map에 들어가기까지

Step 1. SAM2와 SAM3가 서로 다른 2D mask를 만든다

Stream3Dv2는 한 종류의 2D segmentation 결과만 믿지 않는다. SAM2에는 grid prompt를 넣어 화면을 촘촘히 훑는다. 이 branch는 class 이름 없이도 가능한 물체 영역을 넓게 찾지만, 카펫 무늬 하나를 여러 조각으로 나누는 식의 over-segmentation이 생기기 쉽다.

SAM3에는 장면 class text prompt를 넣는다. 이 branch는 mask와 desk 같은 label을 일대일로 연결해 semantic cue를 주지만, prompt 목록 밖의 물체를 놓치거나 한 class의 모든 영역을 충분히 덮지 못할 수 있다. 논문의 설계는 “잘 덮지만 이름이 없는 mask”와 “덜 덮더라도 의미가 있는 mask”를 경쟁시키지 않고 보완재로 사용한다.

두 branch의 2D pixel mask는 depth, intrinsics, camera pose를 이용해 현재 frame의 3D point index 집합으로 바뀐다. 이때 RGB 경계와 depth 경계의 오차, sensor noise, pose 오차가 그대로 3D noise mask가 될 수 있어 이후 단계가 필요하다.

Step 2. 단일 view의 기하 noise를 먼저 버린다

각 3D mask 안의 point는 서로 이어진 manifold를 이뤄야 하고, 서로 다른 instance의 point는 분리돼야 한다는 제약을 둔다. 이 초기 정제 단계에서는 threshold δ를 둔 Euclidean distance를 사용한다. 같은 mask에서 공간적으로 동떨어졌거나 다른 mask 경계를 침범한 point를 보수적으로 버린다.

뒤에서 manifold distance를 쓴다고 해서 전체 pipeline에서 Euclidean distance가 사라진 것은 아니다. Euclidean constraint는 초기 잡음 제거에, manifold metric은 버려진 point를 표면 구조에 맞춰 다시 할당하는 데 각각 쓰인다.

Step 3. 최근 20개 view에서 핵심 mask만 고른다

같은 물체를 여러 각도에서 보면 불완전하고 중복된 mask가 많이 생긴다. Stream3Dv2는 local point cloud에서 farthest point sampling으로 5%의 key point를 뽑고, 이 key point를 모두 덮는 최소한의 mask 집합을 찾는 Set Covering Problem으로 바꾼다. 구현 algorithm은 greedy하게 coverage가 큰 mask를 선택하므로, 여러 view의 모든 mask를 무차별하게 남기는 것보다 noise와 중복을 줄인다.

선택된 key mask끼리 3D IoU가 α=0.2보다 크면 graph edge를 연결한다. 연결 요소 안의 mask point를 합쳐 여러 방향에서 본 동일 instance의 더 완전한 coarse mask를 만든다. 이 단계까지의 결과는 공간적으로 안정적이지만 class 이름이 없는 coarse-grained segmentation이다.

Step 4. Semantic vote와 Set Partitioning으로 붙이고 쪼갠다

최근 frame들에서 같은 3D point가 서로 다른 semantic label을 받으면 가장 자주 나온 label로 투표한다. 중복 semantic mask는 작은 mask를 우선 보존해 서로 겹치지 않게 만들고, 각 semantic mask가 어느 coarse mask 안에 얼마나 포함되는지 계산한다.

그다음 문제를 Set Partitioning Problem으로 표현한다. 하나의 coarse mask가 여러 의미 mask를 충분히 포함하면 그 부분들로 쪼갤지, coarse mask를 그대로 둘지 선택한다. coarse mask와 겹치지 않는 semantic mask는 새 instance로 추가할 수 있다. 예를 들어 grid branch가 책상과 의자를 한 덩어리로 합쳤더라도 semantic branch가 둘을 안정적으로 구분하면, 의미 정보를 hard guidance로 써 두 instance로 나누는 구조다.

이 융합의 장점은 semantic score를 단순 평균하는 대신, mask를 유지·분해·신규 추가하는 명시적인 조합 문제로 만든 데 있다. 반면 결과는 class prompt가 맞게 주어졌다는 가정과 inclusion·overlap threshold에 영향을 받는다.

Step 5. Manifold graph가 버린 point를 표면을 따라 복구한다

앞 단계는 애매한 point를 버리는 방식으로 mask를 깨끗하게 만들었기 때문에 경계에 구멍이 남는다. 단순한 최근접 Euclidean 할당은 얇은 의자 다리나 휘어진 표면에서 가까이 붙어 있는 다른 물체로 건너뛸 수 있다. Stream3Dv2는 local point cloud를 voxel super-point graph로 바꾸고, 각 node의 centroid와 covariance에서 방향성 metric을 만든다.

이 metric은 표면의 접선 방향 이동은 싸게, 표면 법선 방향으로 튀어가는 이동은 비싸게 만든다. 각 instance mask를 source로 둔 multi-source Eikonal distance field를 만들고, iterative Bellman relaxation으로 graph 위 최단 비용을 전파한다. 아직 어느 mask에도 속하지 않은 node는 가장 먼저 도달한 mask에 배정된다. 실험 기본값은 voxel당 평균 20 point, 최대 반복 R=5다.

논문 부록은 충분한 반복에서 finite graph의 shortest-path 해로 수렴하는 성질을 설명한다. 다만 실제 실험은 계산량을 위해 R=5로 잘라 사용하므로, 임의로 큰 graph의 모든 경로를 매번 완전히 탐색한다고 이해해서는 안 된다.

Step 6. AABB로 historical candidate를 좁힌 뒤 갱신한다

Local window의 결과를 과거 전체 mask와 모두 point-to-point 비교하면 시간이 빠르게 늘어난다. 저자들은 각 instance의 axis-aligned bounding box를 만들고 historical AABB를 spatial grid에 미리 색인한다. 현재 local AABB와 겹치지 않는 historical mask는 point-level 비교에서 제외한다.

후보 중 현재 local mask와 실제 point intersection이 있는 mask만 갱신 대상으로 본다. 여러 historical mask와 겹치면 intersection이 가장 큰 instance에 local mask를 합치고, 나머지에서는 해당 point를 빼 instance 간 분리를 유지한다. 어떤 historical mask와도 겹치지 않으면 새 instance로 등록한다.

AABB는 coarse filter일 뿐 최종 association 기준은 아니다. Bounding box가 겹쳐도 point가 겹치지 않으면 같은 instance로 합치지 않는다. 이 2단계 검색이 정확한 point 비교의 대상 수를 줄이는 핵심이다.

Step 7. CLIP label과 detection, LLM agent로 확장한다

논문 구현은 CLIP ViT-H의 image-text matching으로 최종 instance에 open-vocabulary label을 붙인다. SAM3의 semantic mask는 앞선 분할 과정에서 어떤 coarse mask를 쪼갤지 안내하고, CLIP은 최종 semantic labeling을 담당한다. Instance point의 최소·최대 좌표로 AABB를 만들면 open-vocabulary 3D detection 결과도 얻는다.

저자들은 별도 demo에서 Stream3Dv2가 만든 RGB 값과 3D segmentation point cloud file, prompt를 Codex v0.142.0과 gpt-5.5에 넘겨 instance grounding, 장면 reasoning, path navigation, 간접 표현을 이용한 fuzzy query를 보였다. 이것은 object-centric 3D map이 언어 agent의 입력으로 쓸 수 있다는 정성 사례다. 실제 로봇의 closed-loop 성공률이나 안전한 navigation 성능을 측정한 benchmark는 아니다.

5. 실험 설정과 재현에 필요한 값

Parameter analysis에서 k는 평가 범위 내 변화에 비교적 둔감했고, key-point rate γ는 0.001까지 낮추면 성능이 급락했다. δ는 0.03~0.07, α는 0.1~0.3 구간에서 비교적 안정적이었다. 그러나 논문도 δ가 point-cloud density에 따라 달라질 수 있다고 적는다. 다른 sensor와 outdoor map에 기본값을 그대로 옮기기보다는 voxel scale과 depth noise에 맞춰 다시 검증해야 한다.

6. 어떤 데이터셋을 사용했나

세 데이터셋은 모두 실제 실내 장면이지만 sensor noise, point density, frame 밀도와 공간 규모가 다르다. MatterPort3D는 전체 test set이 아니라 논문이 정한 8-scene subset이다. 공개 v1 README도 Mask3D memory 제약 때문에 subset을 쓴다고 설명하므로, MatterPort3D 결과를 dataset 전체 성능으로 확대해 읽으면 안 된다.

평가 metric

  • AP: IoU 0.50부터 0.95까지 0.05 간격으로 계산한 average precision의 평균.
  • AP50: 3D mask IoU 0.50에서의 average precision.
  • AP25: 더 느슨한 IoU 0.25에서의 average precision.
  • Class-agnostic: 물체 class가 맞는지 보지 않고 instance 분리 자체를 평가.
  • Semantic: instance 경계와 class label을 함께 평가.

AP25가 높고 AP가 낮다면 물체의 대략적인 영역은 찾지만 정밀한 3D 경계와 여러 IoU threshold를 꾸준히 만족시키지는 못한다는 뜻이다. 대표 수치 하나보다 AP·AP50·AP25를 함께 보는 편이 안전하다.

7. ScanNet200 class-agnostic 결과

동일 표의 streaming zero-shot 방법끼리 비교하면 Stream3Dv2의 27.1/42.0/55.3이 세 metric 모두 가장 높다. 이전 Stream3D보다 AP +4.7%p, AP50 +4.4%p, AP25 +0.2%p다. 개선 폭이 낮은 IoU의 AP25보다 엄격한 AP와 AP50에서 크다는 점은 단순히 물체를 대략 찾는 수준보다 mask 품질이 좋아졌음을 시사한다.

반면 학습을 사용하는 streaming EmbodiedSAM은 AP 28.8과 AP50 42.7로 Stream3Dv2보다 각각 1.7%p, 0.7%p 높다. 전체 3D segmentation 범위로 넓히면 offline zero-shot MV3DIS가 class-agnostic AP 35.5, supervised Mask3D가 39.7이다. Stream3Dv2의 정확한 강점은 streaming과 zero-shot을 동시에 만족하는 비교군에서 높은 정확도이지, 모든 3D method를 이긴 전체 SOTA가 아니다.

8. ScanNet200 semantic segmentation과 detection

Semantic instance segmentation

Stream3Dv2는 이전 버전보다 semantic AP가 13.0→20.6으로 +7.6%p 올랐다. 전체 sequence를 미리 보는 offline zero-shot MV3DIS의 15.5보다도 5.1%p 높다. AP50은 33.7 대 20.2, AP25는 44.6 대 24.2로 차이가 더 크다. Grid mask만 쓰던 구조에 semantic prompt와 명시적 mask partition을 추가한 효과가 가장 잘 드러나는 결과다.

그렇다고 supervised Mask3D를 완전히 넘어선 것은 아니다. Stream3Dv2의 AP 20.6은 Mask3D 26.9보다 낮고, AP50도 33.7 대 36.2로 낮다. AP25만 44.6 대 41.4로 높다. 느슨한 overlap에서는 경쟁력이 있지만 엄격한 threshold 전체 평균에서는 supervised offline model과 여전히 간격이 있다.

Open-vocabulary 3D object detection

Stream3Dv2는 이전 버전보다 detection AP50이 10.6→14.2, AP25가 18.9→24.8로 올랐다. Offline zero-shot Zoo3D₀와 비교하면 AP50은 0.1%p, AP25는 3.7%p 높다. 학습을 쓰는 offline Zoo3D₁과 비교할 때는 AP25가 1.3%p 높지만 AP50은 1.0%p 낮다. “모든 detection metric에서 모든 baseline을 이겼다”보다, streaming zero-shot 제약에서 offline method와 경쟁 가능한 AABB를 만들었다고 해석하는 것이 정확하다.

9. 다른 실내 데이터셋에서도 유지됐나

이전 Stream3D 대비 class-agnostic AP는 ScanNet++에서 +2.7%p, MatterPort3D에서 +3.8%p 올랐다. Semantic AP는 각각 +6.9%p와 +5.9%p다. 특히 semantic 개선이 두 데이터셋에서도 반복돼 geometric-semantic fusion이 ScanNet200 하나에만 맞은 현상은 아니라는 근거가 된다.

다만 Table I에는 데이터셋마다 결과가 비어 있는 baseline이 많고 MatterPort3D는 8-scene subset이다. 논문 표에 기재된 비교군 범위 안에서는 강한 결과지만, 모든 공개 방법을 동일 protocol로 완전 비교한 순위표라고 보기는 어렵다.

10. Ablation — 어떤 구성요소가 실제로 기여했나

Grid와 semantic prompt의 상보성

Semantic prompt만 쓰면 이름 구분은 상대적으로 낫지만 화면 전체 물체 coverage가 부족해 class-agnostic AP가 14.0에 머문다. Grid만 쓰면 coverage 덕분에 22.4로 오르지만 semantic AP는 13.0이다. 둘을 함께 쓰면 두 metric이 모두 가장 높아진다. “SAM3로 SAM2를 교체”한 것이 아니라 두 모델이 서로 다른 오류를 메우도록 설계한 이유다.

MVF, SDS, PMR 모듈

세 핵심 모듈을 모두 끈 baseline은 ScanNet200에서 class-agnostic AP 16.6, semantic AP 8.0이다. Multi-view noise filtering, Semantic-Driven Segmentation, Point-cloud Manifold Refinement를 모두 켜면 27.1과 20.6이 된다.

  • MVF 단독: ScanNet200 class-agnostic AP50 28.7→32.4. 여러 view의 기하 consistency가 초기 noise를 줄인다.
  • SDS 단독: ScanNet++ semantic AP 1.7→12.8. 의미 기반 분할이 semantic 성능의 주된 driver다.
  • PMR 단독: MatterPort3D class-agnostic AP25 18.4→33.9. 버린 point를 표면에 맞게 복원하는 효과가 큰 장면이 있다.

각 수치는 서로 다른 dataset과 metric에서 저자들이 고른 대표 예시다. 하나의 모듈이 모든 개선을 단독으로 설명한다기보다, 세 모듈의 조합이 대부분 metric에서 가장 좋았다는 것이 ablation의 핵심이다.

11. 효율성 — 11 FPS의 범위와 장기 stream의 비용

ScanNet200 streaming class-agnostic 비교표는 Stream3Dv2를 11 FPS로 적는다. Stream3D 13 FPS와 OnlineAnySeg·MoonSeg3R 15 FPS보다는 느리지만 정확도는 높다. 이번 버전의 semantic branch와 정제 단계가 정확도를 올리는 대신 처리량 일부를 내준 trade-off가 보인다.

그러나 논문은 11 FPS가 RGB-D decode, pose·reconstruction, SAM2, SAM3, CLIP, point-cloud update 중 어디까지 포함하는지, per-scene인지 4-GPU 병렬 전체 throughput인지 상세한 측정 protocol을 같은 표에서 밝히지 않는다. Hardware 설명도 4대의 RTX 4090에 dataset scene을 균등 분배해 병렬 처리했다고만 적는다. 11 FPS를 한 대의 GPU나 M1 Pro, 실제 sensor-to-action loop의 보장 속도로 환산할 수 없다.

긴 sequence에서는 history 비용이 커진다

Scene gxdoqLR6rwA의 장기 실험에서 local 20-frame 처리는 100ms 아래를 유지하지만, local-to-history 시간과 mask-pool memory는 frame 수에 따라 증가한다. 논문도 이 둘이 선형으로 성장한다고 명시한다. 최근 window 덕분에 모든 과거 view를 재처리하지는 않지만, history가 무한히 커져도 시간과 memory가 일정한 구조는 아니다.

AABB candidate filtering 자체의 평균 시간은 frame당 ScanNet200 0.041→0.038ms, ScanNet++ 0.234→0.196ms, MatterPort3D 0.826→0.423ms로 줄었다. 이 숫자는 mask localization subroutine만의 latency다. 11 FPS나 위 표의 전체 local/history 단계와 섞어 “전체 pipeline이 0.038ms”라고 인용하면 안 된다.

12. 이 논문의 장점

  • Streaming과 zero-shot을 함께 다룬다. 미래 frame이나 완성된 전체 scene 없이 현재 관측을 역사 지도에 증분 결합한다.
  • 3D task-specific training이 필요 없다. 새 실내 dataset마다 dense 3D annotation을 만들어 fine-tuning하는 비용을 피한다.
  • Coverage와 의미를 분리해 결합한다. SAM2 grid mask의 넓은 coverage와 SAM3 prompt mask의 class 정보를 동시에 살린다.
  • 2D VFM의 noise를 그대로 누적하지 않는다. single-view geometry, multi-view set cover, IoU graph, semantic partition이 단계별로 오류를 걸러낸다.
  • 곡면 구조를 반영한다. Euclidean nearest point 대신 방향성 manifold graph를 따라 미할당 경계를 채운다.
  • 결과가 object-centric하다. Point mask, label, AABB가 있어 detection, grounding, 공간 질의 같은 downstream task에 연결하기 쉽다.
  • 서로 다른 규모의 실내 dataset에서 개선이 반복된다. ScanNet200뿐 아니라 ScanNet++와 MatterPort3D subset에서도 v1 대비 class-agnostic·semantic AP가 함께 올랐다.

13. 한계와 주의할 점

  • RGB-D와 정확한 calibration·pose가 전제다. Monocular depth나 SLAM error를 모델 내부에서 교정하지 않는다.
  • 실험 범위가 실내 scan에 집중돼 있다. 논문도 unconstrained ultra-large outdoor scene과 dynamic occlusion을 열린 문제로 남긴다.
  • 움직이는 물체 추적을 검증한 논문은 아니다. Historical update의 dynamic이라는 용어와 physical motion tracking은 다르다.
  • Open-vocabulary는 prompt에 의존한다. SAM3에 넣는 common class word와 CLIP candidate vocabulary가 빠진 개념은 semantic mask와 label 품질이 떨어질 수 있다.
  • 전체 3D SOTA는 아니다. Offline zero-shot·supervised method가 더 높은 class-agnostic AP를 기록하고, 학습형 streaming EmbodiedSAM도 일부 metric에서 높다.
  • 장기 history 비용이 남는다. Local-to-history latency와 mask-pool memory가 frame 수에 따라 증가한다.
  • 11 FPS의 측정 범위가 모호하다. End-to-end sensor pipeline이나 특정 단일 GPU에서의 latency로 재해석할 근거가 부족하다.
  • 저자 보고 수치다. arXiv v1에는 반복 실험의 분산·신뢰구간이 없고, v2 공개 구현을 이용한 독립 재현도 아직 어렵다.

14. 코드·라이선스·재현성 상태

2026년 8월 25일 확인 기준, 논문이 연결한 공식 GitHub는 공개돼 있고 저장소에는 MIT LICENSE가 있다. 하지만 repository 제목과 README는 이전 논문 Stream3D이며, root에는 Code_Stream3D_CVPR2026F.zip, README, LICENSE, image만 있다. 논문 초록도 Stream3Dv2 code를 이 저장소에 “업데이트할 예정”이라고 표현한다.

현재 공개 artifact로 확인 가능한 것은 v1 Stream3D pipeline이다. README의 v1 full pipeline은 CropFormer와 OpenCLIP을 안내하고, 이번 v2 논문의 SAM2 grid branch, SAM3 semantic branch, set-partition fusion, manifold update를 그대로 실행하는 최신 source와 config는 repository tree에서 확인되지 않는다. 논문의 headline 수치와 11 FPS를 end-to-end로 재현할 수 있다고 말하기에는 이르다.

저장소의 MIT license는 공개된 v1 code에 적용된다. SAM2·SAM3·CLIP checkpoint, Open3D, ScanNet·ScanNet++·MatterPort3D data에는 각각의 별도 이용 조건이 적용된다. 특히 ScanNet 계열과 MatterPort3D는 공식 절차에 따라 data 접근 권한을 받아야 하므로, repository license 하나만으로 전체 재현 자산을 자유롭게 재배포할 수 있는 것은 아니다. 논문 자체는 arXiv의 perpetual non-exclusive license로 배포됐다.

15. 실무에서 어디에 쓸 수 있나

가장 가까운 적용처는 이미 RGB-D와 pose가 안정적으로 들어오는 실내 mapping system이다.

  • 서비스 로봇이 이동하면서 만드는 object-level indoor map
  • 창고·매장의 open-vocabulary 물체 inventory와 공간 검색
  • AR headset의 room understanding과 “책상 옆 의자” 같은 공간 질의
  • Digital twin 구축 중 새 물체를 증분 반영하는 segmentation layer
  • LLM agent에 point mask, label, AABB를 넘기는 3D grounding 전처리

실제 구현 전 확인할 체크리스트

  • Depth scale과 RGB-depth alignment가 맞는가?
  • Camera intrinsics와 distortion correction을 frame에 정확히 적용했는가?
  • Pose drift로 동일 물체가 여러 historical instance로 갈라지지 않는가?
  • 현장 물체를 포함하도록 SAM3·CLIP class word를 구성했는가?
  • 장기 운용 때 오래된 mask를 압축·병합·삭제할 memory policy가 있는가?
  • 2D VFM 추론까지 포함한 end-to-end p50·p95 latency를 실제 장비에서 측정했는가?
  • 움직이는 사람·문·카트가 많은 장면에서 ID 안정성과 잘못된 merge를 별도 평가했는가?

M1 Pro MacBook에서의 실시간 가능성은 현재 자료만으로 판단하기 어렵다. 논문 평가는 CUDA 기반 RTX 4090 네 대에 scene을 분산했고, 공개 저장소에는 v2 구현이 없다. Apple Silicon에서 SAM2·SAM3·CLIP, point-cloud graph를 함께 돌렸을 때의 memory와 처리량은 code 공개 후 직접 profile해야 한다.

16. 결론 — 이 논문의 진짜 의미

Stream3Dv2의 의미는 더 큰 3D network를 새로 학습한 데 있지 않다. 사전학습된 2D model이 내놓은 불완전한 mask를 최근 view의 기하 consistency, 명시적 semantic partition, 표면-aware graph, 역사 instance update로 조직해 streaming 3D map으로 바꾼 데 있다.

ScanNet200에서 이전 Stream3D 대비 class-agnostic AP는 22.4→27.1, semantic AP는 13.0→20.6, detection AP25는 18.9→24.8로 올랐다. 특히 semantic 성능의 상승은 SAM2 coverage와 SAM3 meaning을 같이 쓰는 설계가 실제 표에서 효과를 냈음을 보여준다.

현재 단계의 판단은 분명하다. 연구 아이디어와 실내 object-map architecture로는 흥미롭지만, 전체 3D SOTA나 검증된 11 FPS end-to-end system으로 포장할 단계는 아니다. 정확한 재현성과 현장 적용성은 Stream3Dv2 source·checkpoint·설정이 공식 저장소에 올라온 뒤, pose error와 장기 memory까지 포함해 다시 확인해야 한다.
